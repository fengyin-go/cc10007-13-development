# 数据分层建模工作台

离线版数仓分层建模工具，覆盖贴源层、明细层、汇总层、应用层的表结构设计、分区策略配置、质量规则编排与血缘关系管理，数据持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

```text
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   │   ├── cleanse-engine.ts      清洗判定、条件卡、行/包护照与质量结论
│   │   └── cleanse-ledger.ts      护照台账（样本包、护照、版本、接收记录）
│   ├── tests/                引擎/服务/持久化/页面/DOM 测试
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install

```

生产构建：

```bash
cd frontend
npm run build
```

## 清洗加工的行护照

清洗加工是主对象。样本经空值替换、格式规范化与异常阈值处理后，参与输出流的每一行都签发一张
**行护照**（`ROW-xxxx`），携带原始值指纹、清洗版本与判定码（`PASS` / `FILL` / `FMT` / `RANGE` /
`ENUM` / `FORMAT`）；被隔离留存的样本同样保留护照与原始值，并必须写明缺席理由。一次处理对应一个
**包护照**（`PKG-xxxx`），包内行护照只能是同一清洗版本。

- **条件卡**：阈值、口径（空值填充值/空值标记）、判定规则与允许范围合成一张卡，随包快照固化，
  后续改规则不会回写旧包。
- **质量校验**按护照计算阻断：完整性、版本一致性、原始值指纹、缺席理由、异常率阈值与阻断一致性。
- **转换编排**只接收同一版本的完整护照包（`src/data/transform-gate.ts`）；节点启用前会复核。
- **重复处理**同一包返回原护照号，只追加一条处理轨迹；候选版本用「按 vX.Y 重签」为同一包另发新护照。
- **失败补齐**只给未盖章样本书护照，已通过 / 已隔离行不重制。
- **回看与还原**：包护照保存原始输入、固化的条件卡与处理轨迹，旧包按自身清洗版本还原。

相关实现：`src/data/cleanse-engine.ts`（判定与护照组装）、`src/data/cleanse-ledger.ts`
（localStorage 台账）、`src/api/cleanse-service.ts`（处理/补齐/接收）、
`src/components/passport/`（条件卡与护照详情）。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-layer-studio:entries` 这一项，或调用 `resetModule(模块)`。
